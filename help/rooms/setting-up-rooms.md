Room management is for the bedrooms you let: a double above the bar, a twin, a single. It is separate from [Spaces](/help/spaces/setting-up-a-function-room/), which is for a function room or boardroom booked as a whole.

## Add a room

Give each room a name guests and staff will both recognise, such as Room 1, and the type: double, twin or single.

Set the rate. A room can be offered as room only or as bed and breakfast. Add a minimum stay when a Friday or Saturday should not be sold as a single night.

Room nights are charged at 20% VAT. Drinks and food keep the VAT already set on the till, which matters when the lot is settled together. See [The room bill](/help/rooms/room-bill/).

Stays are entered in Hospitality App. There is no connection to Booking.com, Expedia or Airbnb.

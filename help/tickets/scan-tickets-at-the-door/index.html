Tickets

Scan tickets at the door

1 min readUpdated 2026-10-16For owner, manager, staff

Scan the QR from a staff phone. Each ticket only scans once.

Every ticket has its own QR code. The guest gets it by email. From the confirmation email, or the paid page, they can add it to Apple Wallet and Google Wallet. Staff still scan the QR at the door.

On the night

Open the event and choose Door, or open Door from the events list. Scan the code with a staff phone.

The scanner checks the ticket in. It flags a code that:

  • has already been scanned
  • has been refunded
  • belongs to a different event

Each ticket only counts once. A second scan of the same code is shown as already used.

Wallet passes

Guests can add the ticket to Apple Wallet and Google Wallet from the confirmation email or the paid page. That is the product. It does not mean Google’s class review is finished, or that Google Wallet is available to every guest. The QR on the pass is the same code the door scans.

Set the door time on the Doors step when you create the event, so the public page shows when to arrive.

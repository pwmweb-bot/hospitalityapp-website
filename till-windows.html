Till for Windows

The till, on your Windows terminal.

Most dedicated EPOS hardware runs Windows, so the till runs on it too. Hospitality App Till for Windows is the same till as on tablets and phones — same menu, tabs, table service, split bills, discounts, end of day and Z report — shown full screen on a touchscreen EPOS terminal, an all-in-one POS PC, or an ordinary Windows PC you already own.

Download for Windows See what the till does

Windows 10 or 11, 64-bit. About 1.7 MB. Installs without admin rights.

Before you start

What you need.

  • Windows 10 or 11, 64-bit. Check Settings → System → About: it should say “64-bit operating system, x64-based processor”. Windows 7, a POSReady edition, a 32-bit install and ARM-based PCs will not run it.
  • A Hospitality App account on Complete, which includes the till. Pricing is per venue, not per device, so a Windows till adds no per-terminal or licence fee.
  • A pairing code, which a manager or owner generates in the app under Settings → Devices.
  • A receipt printer, if you print receipts or open a cash drawer: a receipt printer installed in Windows (a USB thermal ESC/POS printer, for example) or a network receipt printer on your own LAN, on port 9100.
  • An internet connection while you set up. On an older Windows 10 PC the installer first fetches Microsoft’s WebView2 runtime, which is a much larger download and adds a few minutes.
Setting it up

Four steps, about five minutes.

  1. Download and run it. It installs for the signed-in Windows user, so it doesn’t ask for admin rights.
  2. Click past two warnings. The installer isn’t code-signed, so your browser will question the download — in Chrome choose Keep, in Edge choose ⋯ → Keep → Keep anyway. When you run it, Windows shows “Windows protected your PC”: choose More info, then Run anyway. A tablet till needs no such step.
  3. Pair the till. It opens full screen on the pairing page. In the app, go to Settings → Devices, create a code, type it in and name the till. Staff then use their till PIN as normal — no email logins on the till.
  4. Choose the printer. Open Till settings: hold the top-left corner for three seconds, or press Ctrl+Shift+Alt+H, and enter a manager PIN. Pick this PC’s receipt printer, the paper width and the cash drawer, and send a test print.
Day to day

It looks after itself.

  • Starts with Windows, full screen, and won’t browse anywhere else — an outside link hands off to the PC’s normal browser rather than opening in the till.
  • Windows only. There is no Mac or Linux build; on those, use the till in a browser, or a tablet.
  • Recovers on its own. If the internet isn’t there at start-up it waits and retries; if the page crashes or hangs it reloads. It keeps the screen awake.
  • Updates itself when the till is idle, so you don’t download this page again. You can also check for updates from Till settings.
  • Needs a connection to trade. Like the tablet till, it talks to your venue’s data as you ring sales; it isn’t an offline till.
